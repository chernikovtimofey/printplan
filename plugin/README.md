# AI Assistant — плагин-ассистент для STE Slicer

Плагин добавляет в STE Slicer чат с языковой моделью. Пользователь прикрепляет модель (STL, OBJ, 3MF), описывает задачу текстом или прикладывает техническое задание (.docx) и фото, а ассистент:

1. выбирает режим печати (3D, 5D Spiral или 5D Spiral Full), профиль качества, материал, настройки и ориентацию;
2. применяет их в слайсере и ставит модель на стол;
3. нарезает модель и сообщает время печати и расход материала;
4. объясняет решения, называет риски и задаёт уточняющие вопросы;
5. по просьбе сохраняет G-code и проект 3MF.

Основной принтер — **Stereotech Hybrid 530 V5.2.4**.

## Установка

1. В STE Slicer откройте **Справка → Показать конфигурационный каталог**. Откроется `%APPDATA%\steslicer\<версия>\`.
2. Закройте слайсер.
3. Скопируйте папку `AIAssistant` в подпапку `plugins` этой папки: получится `...\steslicer\<версия>\plugins\AIAssistant\plugin.json`. Подпапку `plugins` слайсер создаёт сам при запуске.
4. Запустите слайсер. В меню **Расширения** появится пункт **AI Assistant**.

Дополнительные библиотеки не нужны: плагин использует Python 3.5, numpy и, если он есть, scipy из дистрибутива слайсера.

## Настройка доступа к языковой модели

1. Откройте чат: в меню расширений выберите **AI Assistant → Открыть чат**. Чат откроется в браузере по адресу `http://127.0.0.1:17530/`.
2. Нажмите **⚙** и укажите адрес API, модель и ключ:

| Поле | Значение |
|---|---|
| Адрес API | `https://api.timeweb.ai/v1` (по умолчанию) |
| Модель | `dashscope/qwen3.8-flash` (по умолчанию) |
| Ключ API | ключ вашего OpenAI-совместимого API |

Подробности хранения:
- Ключ сохраняется в настройках слайсера (ключ `ai_assistant/api_key` в файле настроек) и в чат обратно не передаётся.
- В исходниках ключа нет.
- Вместо ввода ключа в форме можно задать переменную окружения `STE_LLM_API_KEY`.

Без ключа плагин тоже работает: план строится по правилам (геометрия, граф материалов), без языковой модели. Объяснение тогда собирается по шаблону.

В тех же настройках задаются папка для G-code и проектов (по умолчанию `%USERPROFILE%\STE-AI-Assistant`), порт локального сервера и адрес сервиса «модель по фото» (по умолчанию `http://127.0.0.1:17600`).

## Как пользоваться

- **Модель и задача.** Перетащите в окно чата модель и, при желании, ТЗ (.docx) и фото, коротко опишите задачу и нажмите «Отправить». Модель сразу появится на столе слайсера. Затем ассистент вызовет `plan_print`: в чате видно каждый этап анализа и каждое действие в слайсере (профиль, материал, режим, настройки, поворот, слайсинг).
- **Карточка плана.** Показывает режим, профиль, материал и ориентацию с причиной, время печати и расход. В раскрывающихся разделах:
  - доводы за 3D/5D;
  - все настройки с причинами;
  - рейтинг материалов;
  - риски, подсказки по конструкции, вопросы.
- **Сохранение.** Под результатом нарезки есть кнопки «Сохранить G-code» и «Сохранить проект 3MF». Они сохраняют файлы в папку вывода под именем модели и показывают путь; языковая модель для этого не нужна. Кнопки неактивны, пока ассистент отвечает, и после изменения модели или настроек — до следующей нарезки.
- **Уточнения** пишите обычным текстом: «сделай заполнение 30 %», «поверни на 90° вокруг X», «смени материал на PETG», «сохрани G-code и проект».
- **Новая модель во вложении заменяет модели на столе.** В чате это видно как шаг «Очистка стола»; вернуть прежние модели можно через Ctrl+Z в слайсере. Несколько моделей, прикреплённых к одному сообщению, загружаются вместе.
- **Новый диалог** очищает историю переписки, но не стол слайсера.

## Модель по фото

Если файла модели нет, прикрепите вместо него фото детали (до четырёх ракурсов) и напишите её наибольший размер в мм, например «диаметр 120 мм». Ассистент построит модель по фото (инструмент `model_from_photos`), поставит её на стол вместо прежних моделей и дальше работает как с обычной STL: план, нарезка, сохранение. Если размера нет, ассистент его спросит.

- **Нужен сервис генерации** `services/photo3d` на компьютере с видеокартой NVIDIA: в самом слайсере нейросеть запустить нельзя. Установка и запуск описаны в `services/photo3d/README.md`. Если сервис на другом компьютере, пробросьте его порт (по умолчанию 17600) на компьютер со слайсером. Без сервиса ассистент сообщит, что генерация недоступна; остальное работает как обычно.
- **Несколько фото** по умолчанию считаются ракурсами спереди, слева, сзади, справа, в порядке прикрепления. Если ракурсы другие, напишите об этом.
- **Модель приблизительная:** точны пропорции и заданный наибольший размер, но отверстия, резьба, зубья и тонкие стенки могут сгладиться. Выбор режима и материала по ней менее надёжен, чем по настоящей модели. Лучше всего подходят фото детали целиком на однородном фоне.
- Генерация занимает от нескольких секунд до пары минут.

## MCP-сервер

Тот же сервер принимает запросы MCP (JSON-RPC 2.0) по адресу `POST http://127.0.0.1:17530/mcp`. Поддерживаются методы `initialize`, `tools/list` и `tools/call`. Адрес также показывает пункт меню **AI Assistant → Адрес MCP-сервера**.

Пример запроса:

```bash
curl -s http://127.0.0.1:17530/mcp -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"get_state","arguments":{}}}'
```

| Группа | Инструменты |
|---|---|
| План | `plan_print` — анализ модели и задания, выбор и применение всех параметров, слайсинг |
| Настройки и профили | `get_state`, `list_quality_profiles`, `list_materials`, `get_settings`, `set_settings`, `reset_settings`, `set_quality_profile`, `set_material`, `set_printing_mode`, `save_profile` |
| Модели | `load_model`, `model_from_photos`, `list_objects`, `get_object_info`, `move_object`, `rotate_object`, `scale_object`, `arrange_all`, `delete_object`, `clear_scene` |
| Слайсинг | `slice`, `get_slice_status`, `export_gcode`, `save_project` |

Вызовы внешних MCP-клиентов тоже показываются в открытом чате, с пометкой «MCP».

## Устройство

```
AIAssistant/
├── plugin.json, __init__.py   # описание плагина для слайсера (api 5)
├── AIAssistant.py             # меню «AI Assistant», запуск сервера, открытие браузера
├── agent/
│   ├── server.py              # HTTP-сервер: чат, /api/*, /mcp
│   ├── agent.py               # диалог с LLM: вызовы инструментов, вложения, работа без LLM
│   ├── tools.py               # инструменты (общие для чата и MCP), plan_print
│   ├── mcp.py                 # JSON-RPC 2.0: initialize, tools/list, tools/call
│   ├── slicer_live.py         # работа с STE Slicer — только через главный поток Qt
│   ├── slicer_fake.py         # слайсер в памяти для тестов и разработки
│   ├── photo3d.py             # клиент сервиса «модель по фото» и масштабирование модели
│   ├── bridge.py, events.py, config.py
├── printplan/                 # анализ: текст, сетка, ось вращения, ориентации, правила, материалы, LLM, проверка
└── web/                       # чат: index.html, app.js, style.css (без внешних библиотек)
```

Сервер слушает только 127.0.0.1. POST-запросы должны иметь тип `application/json`, поэтому сторонняя веб-страница в том же браузере не может управлять слайсером.

## Диагностика

- **Журнал.** Сообщения плагина пишутся в `%APPDATA%\steslicer\<версия>\steslicer.log`, строки с префиксом `[AI]`. Ошибки импорта плагина при запуске — там же и в `%APPDATA%\steslicer\stderr.log`.
- **Пункта «AI Assistant» нет в меню «Расширения».** Проверьте, что `plugin.json` лежит именно в `plugins\AIAssistant\`, а не во вложенной папке вроде `plugins\AIAssistant\AIAssistant\`, и найдите `AIAssistant` в `steslicer.log`.
- **Ошибки инструментов** видны прямо в чате: карточка инструмента с красным крестиком; раскройте её, чтобы увидеть подробности.
- **Порт занят.** Если порт 17530 занят, сервер выбирает свободный; адрес покажет пункт меню «Адрес MCP-сервера».
- **5D требует активации слайсера.** Если 5D-слайсинг не запускается, проверьте лицензию (окно ATSS).

## Разработка без слайсера

Из корня репозитория:

```bash
python tools/dev_server.py --port 17531          # чат на тестовом слайсере в памяти
python -m pytest -q                              # автотесты
```

Для запуска нужен Python 3.5–3.11 с numpy. G-code и проекты, сохранённые тестовым слайсером, помечены как ненастоящие.
