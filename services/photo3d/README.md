# Сервис «модель по фото»

Строит 3D-модель детали по 1–4 фото для плагина AI Assistant (инструмент `model_from_photos`). Плагин работает внутри STE Slicer на Python 3.5 без PyTorch, поэтому генерация вынесена в отдельный сервис на компьютере с видеокартой NVIDIA.

- **Модель:** [Hunyuan3D-2](https://github.com/Tencent-Hunyuan/Hunyuan3D-2) (Tencent), только форма, без текстуры.
  - одно фото — `tencent/Hunyuan3D-2`;
  - несколько фото — `tencent/Hunyuan3D-2mv` с ракурсами спереди, слева, сзади, справа.
- **Скорость:** по умолчанию turbo-варианты (5 шагов); `--quality` включает полные модели (30 шагов, медленнее).
- **Обработка:** фон удаляется автоматически (rembg). Сетка очищается от «островков» и упрощается до 200 тыс. треугольников.
- **Ответ:** STL в осях слайсера (Z вверх) с наибольшим габаритом 1. Реальный размер плагин задаёт сам по размеру, который указал пользователь.
- **Лицензия** Tencent Hunyuan 3D 2.0 Community License: действует везде, кроме ЕС, Великобритании и Южной Кореи.

## Установка

Нужны Python 3.10 и видеокарта с CUDA (проверено на Tesla V100 32 ГБ; на одну модель нужно около 6 ГБ видеопамяти).

```bash
conda create -n ste-photo3d python=3.10 pip
conda activate ste-photo3d
pip install torch==2.5.1 torchvision==0.20.1 --index-url https://download.pytorch.org/whl/cu121
git clone --depth 1 https://github.com/Tencent-Hunyuan/Hunyuan3D-2 third_party/Hunyuan3D-2
pip install -r services/photo3d/requirements.txt
pip install --no-deps -e third_party/Hunyuan3D-2
```

При первом запуске веса скачиваются с Hugging Face, несколько гигабайт.

## Запуск

```bash
python services/photo3d/server.py                      # http://127.0.0.1:17600, модели на cuda:0 и cuda:1
python services/photo3d/server.py --devices cuda:0     # одна видеокарта на обе модели
python services/photo3d/server.py --generate фото.jpg --out деталь.stl   # разовая генерация для проверки
```

- `GET /health` — готовность и загруженные модели.
- `POST /generate` — `{"images": [{"view": "front", "data": "<base64>"}], "seed": 1234}` → `{"stl": "<base64>", "triangles": N, "seconds": t, "model": "..."}`.

Сервис слушает только 127.0.0.1. Если он запущен на другом компьютере, пробросьте порт 17600 на компьютер со слайсером. При работе через VS Code Remote: панель **Ports** → **Forward a Port** → `17600`. В плагине адрес задаётся в настройках чата (⚙ → «Сервис „модель по фото“»), по умолчанию `http://127.0.0.1:17600`.

## Ограничения

- Модель по фото **приблизительная**: точны пропорции и заданный наибольший размер, но отверстия, резьба, зубья и тонкие стенки могут сгладиться или исчезнуть. Выбор режима 3D/5D и материала по такой модели менее надёжен, чем по настоящей.
- Лучше всего работают фото детали целиком на однородном фоне без бликов. Для нескольких фото — ракурсы спереди, слева, сзади, справа, в этом порядке, если пользователь не указал другое.
